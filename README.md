StreamYT – External Tools
This repository provides the two executables StreamYT needs to extract and convert audio from YouTube:
- tools/ffmpeg.exe — FFmpeg 9.0.2 Essentials, built by Gyan.
- tools/yt-dlp.exe — yt-dlp 2026.08.19.
Installation
1. Download StreamYT-tools-v1.0.zip from the Releases section.
2. Extract the ZIP. You will get a folder named tools containing both executables.
3. Copy that tools folder into the StreamYT mod folder. If Windows asks whether you want to merge or replace files, accept.
4. The final folder structure should look like this:
StreamYT/tools/ffmpeg.exe

StreamYT/tools/yt-dlp.exe

The mod does not include these executables in the Steam Workshop release. Without them, the mod can load, but extracting and playing YouTube links will not work.
